# Round Robin CPU Scheduling (C)

## Aim
To implement the Round Robin CPU Scheduling algorithm and calculate each process's waiting time, turnaround time, and the average values.

## Input used
- Processes: P1, P2, P3
- Burst times: 10, 5, 8
- Time quantum: 2

## How to compile and run
Using GCC:

```bash
gcc main.c -o round_robin
./round_robin
```

On Windows, run the compiled program with:

```bash
round_robin.exe
```

## Concepts used
- CPU scheduling
- Round Robin scheduling
- Waiting time
- Turnaround time

Note: The program uses a variable-length array, supported by GCC in C mode.
